# Employee Training Tracker

A Django-based web application for managing employees, training courses, enrollments, and training progress.

## Features

- Employee management
- Training course management
- Employee enrollment tracking
- Training progress tracking
- Dashboard
- Certificate generation
- Login authentication

## Technologies Used

- Python
- Django
- HTML
- CSS
- Bootstrap

## Project Structure

- `employee_tracker/` - Django project configuration
- `training/` - Main application
- `templates/` - HTML templates
- `manage.py` - Django management file

## How to Run

```bash
python manage.py runserver
